# Bluetooth

Open **Galaxy → Tools → Bluetooth** while parked. Turn on Bluetooth, then use **Pair phone** or scan and press **Pair** beside a device. Confirm its code on both devices. **Connect**, **Disconnect**, and **Forget** manage saved pairings.

**Controller Buttons** assigns USB or Bluetooth gamepad, keyboard, or macropad buttons to Quick Select and driving screen actions. Turn off the vehicle before editing. **Test buttons (20s)** checks the input. These buttons do not control steering or pedals.

For music from your phone or Spotify, use **StarPort → Spotify and Phone Audio**. Pair the phone here first if using phone audio.

Comma 3 and 3X Big UI also has a [Bluetooth screen](../assets/images/bluetooth/galaxy_bluetooth_6.png) for managing connections. Examples of add-on controls include a [round controller](../assets/images/bluetooth/galaxy_bluetooth_3.png) and a [strap controller](../assets/images/bluetooth/galaxy_bluetooth_4.png).
